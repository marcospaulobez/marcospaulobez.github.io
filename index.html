Portal de Vagas (Sistema de Recrutamento RH)

Função: Desenvolvedor Full Stack | Projeto Pessoal implantado para Unimed (2024)

Desenvolvi uma plataforma de recrutamento com gestão de candidatos, triagem automatizada, dashboard de analytics (Chart.js) e acesso baseado em funções. Escalou para mais de 11.000 usuários e 1.200+ vagas postadas, reduzindo o tempo de contratação em 40%.

Usei filas Redis para processar mais de 500+ uploads diários de CV e otimizei consultas SQL para 10.000+ registros.

Stack tecnológica: Laravel, Bootstrap, JavaScript, Livewire, jQuery, Chart.js, MySQL, Redis

Sistema de Gestão de Treinamentos

Função: Desenvolvedor Full Stack | Unimed Regional Jaú (2024)

Construí uma plataforma completa de treinamento com calendário dinâmico, presença baseada em QR code, pesquisas de feedback de funcionários e dashboards interativos usando ApexCharts.

Alcancei 95%+ de precisão na presença e reduzi o tempo de onboarding em 20%. Habilitei decisões baseadas em dados através de visualizações claras do ROI e engajamento de treinamento.

Stack tecnológica: Laravel, Livewire, PostgreSQL, Bootstrap 5, JavaScript, ApexCharts

Sistema Easy Biometry

Função: Desenvolvedor Full Stack (Especialista em Integração IA) | Unimed Regional Jaú (2024)

Desenvolvi um sistema de verificação de identidade de pacientes usando DeepStack AI, com fluxos de consentimento integrados e um portal administrativo completo para auditoria e logs.

Alcancei 99.7% de precisão na correspondência facial e reduzi significativamente os riscos de fraude no onboarding de pacientes. O sistema processa mais de 300+ transações biométricas mensais via uma API REST compatível com HIPAA.

Stack tecnológica: Laravel, Python, DeepStack (Reconhecimento Facial), REST API, Bootstrap
